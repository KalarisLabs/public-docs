## Key points

- The barrier is φ(c) = β·exp(γc / (1 − c)) on normalised context use c ∈ [0, 1). It is smooth, increasing, convex and unbounded as c → 1.
- Any barrier that is unbounded as c → 1 caps a rational agent's utilisation below 1. Linear and polynomial prices do not.
- The exponential form keeps that cap more stable than a logarithmic barrier when the agent mis-estimates its value of information.
- In a 50-agent simulator built on the Generative Agents architecture, barrier pricing (β = 0.5, γ = 4) raised task success from 0.42 under linear pricing to 0.73. It lowered cognitive-collapse events from 12.4 to 1.4 per 1,000 steps and raised context efficiency from 0.31 to 0.74 (means over 20 seeds).

## Limitations

These are simulation results with a simplified compression model. They have not been replicated on production agents.

## Abstract

> A language-model agent that works for hours or days eventually fills its context window. Most agents deal with this through truncation, sliding windows, or a flat token budget, and all of these charge the same price for the last token as for the first. We argue that this is the wrong price. Treating context as a scarce resource, we ask which cost function makes a self-interested agent compress its memory early instead of at the edge of failure. We study an exponential barrier φ(c) = β exp γc/(1 − c) on normalised context use c ∈ [0, 1). We show that it is smooth, increasing, convex and unbounded as c → 1, and we prove that any barrier with that last property caps the utilisation of a rational agent below 1, while linear and polynomial prices do not. The exponential form differs from the logarithmic barrier in how stable that cap is when the agent's value of information is mis-estimated. In a simulator of 50 agents built on the Generative Agents architecture, barrier pricing (β = 0.5, γ = 4) raised task success from 0.42 under linear pricing to 0.73, lowered cognitive-collapse events from 12.4 to 1.4 per 1000 steps, and raised context efficiency from 0.31 to 0.74 (means over 20 seeds). These are simulation results with a simplified compression model, and they have not been replicated on production agents.
