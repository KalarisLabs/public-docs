**Kalaris Labs is an applied AI research lab, founded in India in 2026, that builds infrastructure for the agentic
era.** We publish our research as open preprints, release the code under open-source licenses, and document what
works today separately from what is only designed.

## What we work on

| Area | Question | Work |
|---|---|---|
| Self-improving agents | How can an agent change its own harness without breaking what worked? | [Kalki](/kalki), [Agent Kalki](/research/papers/agent-kalki), [Viveka](/research/papers/viveka), [TailHorizon](/research/papers/tailhorizon) |
| Evaluation | Which results deserve to be believed? | [PrincipalBench v2](/benchmarks/principalbench), [HiddenLaw](/benchmarks/hiddenlaw), [evaluation principles](/benchmarks/evaluation-principles) |
| Agent economies | What keeps markets of autonomous agents stable? | [Agent economies series](/research/agent-economies) |
| Agent security | How do we trust skills, tools and content an agent reads? | [Skill Doctor](/skill-doctor), [economic safeguards against prompt injection](/research/papers/economic-safeguards-indirect-prompt-injection) |
| Efficient inference | How do capable models run on phones and consumer hardware? | [Anudhi](/research/papers/anudhi), [Pipit](/research/papers/pipit), [Banyan](/research/papers/banyan), [LocalLink](/tools/locallink) |
| Agents for science | How do agents do rigorous research work? | [Research Agent Skills](/research-agent-skills), [Myriad](/tools/myriad), [Falsify](/tools/falsify) |
| Agent networking | How do agents and robots find and call each other? | [AMARA](/amara) |

## How we report results

Every paper page states its evidence level: proposal, partial implementation, simulation or experiment. We state
limitations next to the results, and we withdraw results that do not hold up, as with the
[PrincipalBench v1 rankings](/research/papers/principalbench-v2). The rules we hold our own claims to are on the
[evaluation principles](/benchmarks/evaluation-principles) page.
