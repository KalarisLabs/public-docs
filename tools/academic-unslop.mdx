**Academic Unslop is an agent skill that revises academic writing conservatively: minimal edits, protected evidence
and citations, and fewer traceable AI-writing patterns.** It supports English and Chinese and is compatible with more
than 25 agent harnesses, including Claude Code, Cursor, Codex, Gemini CLI and GitHub Copilot.

<Warning>
This is not a detector-bypass tool and it does not guarantee any AI-detector score. It focuses on evidence-preserving
revision and academic integrity.
</Warning>

<Tabs>
  <Tab title="skills CLI">

## What it supports

- Minimal-edit revision chapter by chapter.
- Protected academic elements, such as citations, data and technical terms.
- Routing between qualitative and quantitative writing.
- Awareness of Turnitin AI and CNKI AIGC detection for risk reduction, without bypass claims.
