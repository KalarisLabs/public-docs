**This archive collects the system prompts Anthropic publishes for claude.ai and the Claude mobile apps, copied
exactly, with dates and source links.** It covers 23 models and 50 published prompt versions, from Claude Haiku 3
(July 2024) to Claude Fable 5.2 (November 2026).

| What | Where |
|---|---|
| Every archived prompt, with version history and source link | `models/<model>/system-prompt.md` |
| Index of models and versions | [`models/README.md`](https://github.com/KalarisLabs/claude-systems-prompts/blob/main/models/README.md) |
| Deep dive on the flagship prompt and its tool definitions | [`system-prompt/`](https://github.com/KalarisLabs/claude-systems-prompts/tree/main/system-prompt) |
| Notable findings across the prompt family | [`highlights/`](https://github.com/KalarisLabs/claude-systems-prompts/tree/main/highlights) |

<Note>
These prompts apply to claude.ai and the Claude apps, not to the Claude API. The canonical source for each prompt is
Anthropic's [system prompt release notes](https://platform.claude.com/docs/en/release-notes/system-prompts). The
archive's analysis sections are Kalaris Labs commentary, not Anthropic documentation.
</Note>

## Who uses it

- Engineers studying how production system prompts handle refusals, formatting and tool use.
- Safety and alignment researchers comparing dated versions to study drift.
- Educators and journalists who need the original text rather than a paraphrase.
