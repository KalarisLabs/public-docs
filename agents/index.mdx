**Every page on this site is readable by an AI agent, and every Kalaris Labs product with an agent interface has an MCP
server.** Pick the endpoint that matches what your agent needs.

## Read these docs

| Endpoint | Use it to | URL |
|---|---|---|
| Docs MCP server | Search and read these docs from an MCP client | `https://docs.kalarislabs.com/mcp` |
| `llms.txt` | Get an index of every page with descriptions | [docs.kalarislabs.com/llms.txt](https://docs.kalarislabs.com/llms.txt) |
| `llms-full.txt` | Load the whole site as one Markdown file | [docs.kalarislabs.com/llms-full.txt](https://docs.kalarislabs.com/llms-full.txt) |
| `skill.md` | Load a capability summary of our products as an agent skill | [docs.kalarislabs.com/skill.md](https://docs.kalarislabs.com/skill.md) |
| Markdown pages | Read any single page as Markdown | Append `.md` to a page URL, for example [/research.md](https://docs.kalarislabs.com/research.md) |

Mintlify hosts these endpoints and regenerates them when the docs change. `skill.md` can take up to 24 hours to update.
The menu at the top of each page can also copy the page as Markdown, open it in ChatGPT, Claude or Perplexity, or install
the docs MCP server in Cursor or VS Code.

Add the docs to Claude Code:

```bash
claude mcp add --transport http kalaris-docs https://docs.kalarislabs.com/mcp
```

Add our products' skills to any agent that supports the skills CLI:

```bash
npx skills add https://docs.kalarislabs.com
```

## Use our products

| Product | Interface | Endpoint or command |
|---|---|---|
| [Kuchi](/kuchi/connect) | Remote MCP, Streamable HTTP, no sign-in | `https://kuchi.kalarislabs.com/mcp` |
| [Skill Doctor](/skill-doctor/mcp) | Local MCP over stdio | `npx -y @security.kalarislabs/skill-doctor mcp` |

| [Research Agent Skills](/research-agent-skills/getting-started/installation) | Agent Skills | `npx research-agent-skills` |
| [Academic Unslop](/tools/academic-unslop) | Agent Skills | `npx skills add KalarisLabs/academic-unslop-skill` |

See [MCP servers](/agents/mcp-servers) for configuration in each client.

## Guidance for agents reading this site

- Cite papers by DOI. Each paper page lists its DOI and a BibTeX entry.
- Check a paper's **Evidence** row before repeating a result. Simulation results are not deployment results, and
  proposals report no results.
- Do not repeat the PrincipalBench v1 model rankings. They are withdrawn.
- Kalki is pre-release. Run it only in a container or virtual machine.
